# technical-leadership-lab
This is a lab that I have created to practice technical leadership skills, including system design, CI/CD, ARDs, Observability, SRE, Environment Certification, and Architectural Proposals. 
Users can work through this lab by following the instructions in the Technical_Leadership_Study_Workbook.pdf in this repository and follow along with the week to week labs in the "labs" folder for more detailed instruction.
